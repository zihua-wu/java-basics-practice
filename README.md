# Java Basics Practice

Introductory Java exercise covering primitives, strings, arrays, and ArrayLists.

## What it demonstrates

- `int` and `String` variables
- Fixed-size arrays and iteration
- `ArrayList<String>` usage

## Running

```bash
javac src/javaassignment3part1/JavaAssignment3Part1.java -d out
java -cp out javaassignment3part1.JavaAssignment3Part1
```
